# Documentation

Place the Markit PRD in this directory.

Suggested structure:

```text
docs/
├── PRD.md
├── performance-methodology.md
├── bottleneck-taxonomy.md
├── causal-experiments.md
├── mechanism-comparison.md
└── adr/
```

Only create an ADR after the underlying decision is mature enough to be treated as an architectural commitment.

Performance documents should clearly distinguish:

- observation;
- measurement;
- inference;
- causal evidence;
- design decision.
