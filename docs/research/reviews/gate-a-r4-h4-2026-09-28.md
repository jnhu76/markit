- swift-syntax: restart authority = ALWAYS file start, no restart search; restart state = previous tree + LookaheadRanges ([RawSyntax.ID: Int]) + ConcurrentEdits (pre-edit coords); forward parsing = lazy LexemeSequence cursor; candidate discovery = monotone in-order SyntaxCursor walk, consult at EVERY CodeBlockItem/MemberBlockItem start (only two consult kinds); convergence predicate = byte-local: translated pre-edit position equality + expected-kind equality + (all edits before node OR no edit intersectsOrTouches [pos, pos+lookahead)) — no parser-state comparison; suffix reuse = per-item, INTERLEAVED with fresh parses (reuse item A, reparse B, reuse C), lexer `advance(by:)` skips unlexed bytes; damage-crossing = lazy per item (position inside inserted region → nil); coordinates = never stored, DERIVED lazily by sibling accumulation; EOF/no-convergence = no fallback mode, continuous degradation; retained-state = re-register affect range at EVERY item (fresh or reused) → self-contained.
