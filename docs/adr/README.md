# Architecture Decision Records

This directory contains accepted architectural decisions.

Do **not** create ADRs for unverified performance hypotheses.

A performance-related ADR should normally reference:

1. observed problem;
2. benchmark/workload;
3. attribution evidence;
4. scaling evidence;
5. intervention/causal evidence;
6. alternatives considered;
7. trade-offs;
8. decision.

Suggested naming:

```text
0001-short-title.md
0002-short-title.md
```
